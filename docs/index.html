What Pulse measures

📊

Tasks completed, not tool calls

Hero metric is outcomes — what got done today. Activity metrics are secondary context.

🔄

Debug cycles

Detects error→fix patterns automatically. Shows which files cause the most rework.

🧠

Think-Time

Time between agent completion and your next prompt. Not waste — it's where decisions happen.

📈

Deadline forecasts

Based on historical velocity and debug overhead. "At current pace, you'll finish by Thursday."

🔍

Auto task detection

Recognizes completed tasks from git commits, passing tests, and prompt transitions.

🗂️

Project portfolio

All projects in one view, grouped by category. One-time and continuous projects distinguished.

Design principles

Clarity

Every element earns its place. No decorative noise. Content is the interface.

Color = Meaning

● green = good   ○ yellow = attention   ! red = problem   · dim = secondary

Consistency

Same markers, same colors, same spacing — everywhere. One design system (theme.py) drives all views.
